# Triage Labels

Skills speak in five canonical triage roles. This table maps them to the label
strings in this repo's tracker.

| Canonical role    | Label in our tracker | Meaning                                  |
| ----------------- | -------------------- | ---------------------------------------- |
| `needs-triage`    | `needs-triage`       | Maintainer needs to evaluate this issue  |
| `needs-info`      | `needs-info`         | Waiting on reporter for more information |
| `ready-for-agent` | `agent-ready`        | Fully specified, ready for an AFK agent  |
| `ready-for-human` | `human-ready`        | Requires a human decision or action      |
| `wontfix`         | `wontfix`            | Will not be actioned                     |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the
corresponding label from this table.
