# Coverage matrix of the fir corpus

Generated by `scripts/harness/coverage.py` from the tests of
[`tests/fir/`](../../tests/fir/README.md); do not edit it or its
pages by hand. Run `python3 scripts/harness/coverage.py --write`
after changing the corpus. The `coverage-matrix` hook fails when a
page is stale or a cell has no test. What a cell is, which widths
each side covers and what a test exercises are decided in
[ADR-2026-11-03-0557](../adrs/2026-11-03-0557-a-generated-matrix-counts-the-tests-of-each-cell.md).

Each number is how many tests of the side exercise the cell: the
ops of the function a test runs and of every function it calls, in
its own module or in a nested one such as a kernel's, and, in the
`func` rows, the results of the function it runs. An empty entry is
not a cell: a width change that the spec does not allow, a
conversion from a format to itself, or a width for a row that
passes no value.
