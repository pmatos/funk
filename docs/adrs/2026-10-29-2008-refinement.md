# Correctness means refinement of observable behaviour

Status: accepted
Tier: direction; area: semantics

## Decision

- A target is correct if each of its observable behaviours is allowed by the
  source. Source UB allows anything that first shows the source's events
  before the UB (ADR-2026-11-09-1540). A poison result is refined by any
  value.
- Refinement is defined over a domain of observations that the semantics
  supplies, not hard-wired to integer return values. Each dialect supplies
  its observations (G0, ADR-2026-10-29-2016), and ADR-2026-11-09-1322 says
  how a dialect brings its own behaviour model.
- Functions, `ret` and `call` have any number of results, none included, and
  no validation rule limits them. What a returning M0 run shows is the list
  of its returned values, each a value or poison (`Core.Obs`), and
  refinement compares it value by value. `fir-ref`'s output, the harness's
  expected results and declared results are lists of values.
- In M0, a function's observable behaviour is its returned values, UB, or
  non-termination (fuel exhausted). M1 makes it a trace judged for each world
  (ADR-2026-11-09-1540); the relation stays the same.
- The differential harness compares a native result with the `fir-ref`
  result by refinement. A test whose `fir-ref` result is UB is invalid,
  never a pass. Any later check, such as per-compile refinement checking
  (S8), checks this relation and no other.

This is S4 of the fir v0 decision record, agreed on 2026-10-29 (#5). The
human ruled on 2026-10-30 that M0 too has any number of results (choice 5 of
the rulings comment on #5).
[semantics-refinement.md](../decisions/semantics-refinement.md) states what
holds.

## Why

Funk checks its hand-written Rust, such as backends, against the Lean
semantics. That needs one precise meaning of "this target is correct for
this source". Source and target need not behave identically: where the
source has UB or poison, the target is free to do more than one thing. One
grammar serves every dialect, as in MLIR, so the observation is a list of
values, not one.

## Rejected alternatives

- **Identical behaviour of source and target.** It leaves the target no
  freedom where the source has UB or poison.
- **At most one result in M0,** enforced by validation with the grammar
  kept general, as the review of PR #29 recommended. The human overrode it.
